# 《오늘도 너를 좋아해》創作需求與劇情規格

本文件整理作者在對話中提出的需求，作為本故事的持續修改依據。可遊玩的正式資料仍以同目錄的 `story.json` 為準；不重寫 Phone Runtime、App UI 或共用事件引擎。

## 核心設定

- 主題：以 NMIXX 成員金지우（김지우）與 설윤아（薛侖娥／설윤아）為主角的虛構戀愛「撿手機」互動故事。
- 故事標題：**오늘도 너를 좋아해**（今天也喜歡你）。
- 玩家視角：金智佑的手機；主要感情線是智佑與윤아언니之間從日常關心、曖昧試探到坦白心意。
- 人物描寫以溫柔、自然、帶有玩笑的虛構情境呈現；不要把劇情當成真實人物私生活或真實關係的陳述。
- 手機介面、系統提示、App 名稱與一般手機內容使用韓文。Lily 的聊天可自然使用英文，符合她在團體聊天室中的語言習慣。

## 手機與素材要求

- 解鎖密碼：`0413`。
- P1：作者提供的原圖，用作鎖定畫面／主畫面桌布；保留原圖，不以 AI 重繪或修改。
- P2：作者提供的原圖，用作 KakaoTalk 聯絡人「윤아언니」的頭像；保留原圖。
- P3：作者提供的原圖，用作 Instagram 快拍素材；保留原圖。
- 原始媒體已內嵌在 `story.json` 的安全 data URL 欄位中。編輯劇情時不得用佔位圖覆蓋，也不得把圖片轉成外部未授權連結。

## KakaoTalk 與角色聊天室

- 主要私聊對象為「윤아언니」，由她主動開啟對話；對話要有自然的來回、關心、撒嬌、試探、吃醋與讓人心動的小細節。
- 團體聊天室包含智佑、윤아、해원、릴리、배、규진。每位成員的發言要有可辨識的個性，不應只重複主線戀愛梗。
- 해원：可靠、有責任感、照顧成員，偶爾用務實語氣吐槽。
- 릴리：開朗、反應直接、常用英文與誇張但真誠的祝賀。
- 배：古靈精怪、擅長觀察氣氛，喜歡用玩笑拆穿曖昧。
- 규진：活力充沛、好奇、會撒嬌並調皮地起鬨。
- 另外保留家人與經紀人等日常對話，讓手機內容像真實生活而非只有戀愛訊息。
- 現有主要 KakaoTalk 私聊 53 則、團體聊天室 23 則，及其他成員／家人聊天室；修改時維持對話時間線與人物口吻一致。

## 跨 App 劇情與互動

- Instagram 快拍、貼文、相片、備忘錄、行事曆、Safari、電話與 X 等內容共同推進故事。
- 對윤아的 Instagram 快拍按讚後，觸發她打來的模擬來電；玩家可選擇接聽或拒接，兩種選擇都要有對應後續。
- 接聽後可選擇不同相處方式，導向不同結局；拒接則進入錯過時機的分支。
- 閱讀聊天線索可解鎖隱藏備忘錄；閱讀備忘錄、親密好友快拍或相關內容，可逐步解鎖未送出的訊息與拍立得。
- 保留多結局：떡볶이집 고백、천천히 함께 걷는 밤、서로의 속도로 시작하는 비밀 약속、오늘은 용기를 내지 못했다、숨겨 둔 깜짝 선물。
- 每個結局、密碼、隱藏內容、電話與跨 App 事件都必須有對應的 story test 路徑。

## 修改與交付規則

1. 優先只編輯 `stories/jiwoo-yuna/story.json` 和本需求文件；沿用既有 Phone Runtime、App registry、事件引擎及資料 schema。
2. 保留原始圖片、現有功能、MIT 與依賴授權聲明；不要重寫整個手機 UI。
3. 新增或修改劇情後遞增 `revision`，維持穩定且唯一的英文 ID。
4. 必須執行：
   - `npm run story:validate -- stories/jiwoo-yuna/story.json`
   - `npm run story:test -- stories/jiwoo-yuna/story.json`
   - `npm run build`
5. 本作品預覽命令：
   `STORY_FILE=stories/jiwoo-yuna/story.json npm run story:preview`
   在 Codespaces 的 **Ports** 面板開啟轉發的 5175 埠。不要把內網 IP 當成公開預覽網址。
6. 只有在實際確認 GitHub Actions／Pages 部署成功後，才提供公開預覽網址；未部署時應如實標示為尚未發布。
